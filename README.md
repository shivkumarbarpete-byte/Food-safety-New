# Food Safety Hub

## About
Food Safety Hub is a full-stack food safety analyzer that checks products for FSSAI-compliant safety using barcode scanning, OCR label detection, and a custom-trained k-NN machine learning model on real user data.

🔗 **Live Demo:** [https://food-safety-new.vercel.app/](https://food-safety-new.vercel.app/)
